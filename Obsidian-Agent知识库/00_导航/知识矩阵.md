# Agent 知识矩阵 · 层 × 环

横轴是一次运行的时间轴，纵轴是对象层级。**同一个概念落在哪一格，就说明它插在系统的哪里。**

每格中的概念用双链列出，点进去就是该概念的笔记。空格子代表目前没有独立概念——也可能是尚未被单独命名的问题点。
