# 落位规则 · 新概念三问

> 这张图的第一性产物不是概念清单，而是这套定位规则。概念会过时，规则不会。

## 为什么需要坐标系

觉得「什么都是新的」，通常不是知识不够，而是没有坐标系。有坐标系时，任何新概念都能被还原为「某个已知概念在某个格子里的一次变体」。因此本图的第一性产物不是概念清单，而是定位规则。

## 三条轴

### 层轴 — 它作用在哪一层对象上？

从模型到系统，七层对象栈。绝大多数新名词都住在其中一层。

| 代码 | 名称 | 回答的问题 |
|---|---|---|
| `L0` | 模型层 | 模型本身能做什么？ |
| `L1` | 上下文层 | 本次调用，模型眼前摆着什么？ |
| `L2` | 记忆层 | 这一轮之后，什么被记住了？ |
| `L3` | 工具层 | Agent 通过什么改变外部世界？ |
| `L4` | 控制层 | 谁决定下一步做什么？ |
| `L5` | 编排层 | 多个决策主体如何分工与合流？ |
| `L6` | 系统层 | 如何让它稳定、可观测、可负担、可演进？ |

### 环轴 — 它在一次运行的第几步起作用？

Agent 的一次运行是一个环。任何技术点都能定位到它插在环的哪一段。系统层（L6）不在环上，单独作为支架带呈现。

| 代码 | 名称 | 回答的问题 |
|---|---|---|
| `P1` | 输入 | 接到什么请求？ |
| `P2` | 取景 | 这次给它看什么？ |
| `P3` | 规划 | 打算怎么做？ |
| `P4` | 行动 | 动了什么手？ |
| `P5` | 观察 | 外面回了什么？ |
| `P6` | 反思 | 刚才做得对不对？ |
| `P7` | 交付 | 交出去的是什么？ |

### 面轴 — 它回答的是哪一类工程问题？

同一个概念在不同面上有完全不同的关注点，这一轴决定你去查什么资料。

| 代码 | 名称 | 回答的问题 |
|---|---|---|
| `F1` | 定义 | 这是什么，边界在哪？ |
| `F2` | 机制 | 怎么实现，内部怎么转？ |
| `F3` | 质量 | 怎么判断它做得好不好？ |
| `F4` | 成本 | 花多少 token、多少钱、多少算力？ |
| `F5` | 时延 | 用户要等多久？ |
| `F6` | 安全 | 会不会被搞坏，会不会搞出事？ |
| `F7` | 运维 | 怎么长期跑、怎么演进？ |

## 五步流程

### 1. 先问层

它在七层对象栈的哪一层？判据是「它操作的对象是什么」：token（L1）、跨会话状态（L2）、外部系统（L3）、下一步决策（L4）、多个主体（L5）、运行环境（L6）、模型能力（L0）。

> [!caution] 易错
> 大多数误判来自把「使用场景」当成「层」。例如「客服 Agent」不是一层，它横跨 L1–L6。

### 2. 再问环

它插在运行的第几步？如果它同时出现在多步，取「它主要解决哪一步的痛点」。环的定位决定你什么时候该用它。

> [!caution] 易错
> 把「属于某一步」误当成「只在那一步生效」。上下文工程贯穿 P2–P6，但主战场是 P2。

### 3. 最后问面

它回答的是定义、机制、质量、成本、时延、安全还是运维？这一问决定你该去找什么类型的材料：论文、文档、benchmark，还是事故复盘。

> [!caution] 易错
> 同一个概念常跨多个面。例如 MCP：机制面是协议规范，安全面是工具投毒，运维面是版本治理。

### 4. 定位后做减法

查一下这个格子里已经有什么。如果已有 3 个已知节点，新概念多半是它们的组合或变体。把「它新在哪」写成一句话；写不出来，说明它不新。

> [!caution] 易错
> 跳过这一步，就会把每个新名词都当成独立知识点，形成无限扩张的待学清单。

### 5. 补一条谱系

逼自己回答：它是谁的下一代？前身是什么？被它替代的是什么？这条谱系比定义更能防止「觉得新」。

> [!caution] 易错
> 确实无前身的真新事物很少，通常是新约束（更长上下文、更便宜推理）让旧想法重新可行。这种情况谱系写作「旧想法 + 新约束」。

## 一个例子：把 MCP 落位

1. **层**：它操作的是「Agent 能对外做什么」——L3 工具层，不是模型层。
2. **环**：它生效在 P4 行动（每次发起工具调用），不改变 P2 取景。
3. **面**：机制面看协议规范；安全面看工具投毒；运维面看版本治理。
4. **减法**：格子里已有「原生工具调用」「工具定义」。MCP 不是新能力，是**把 M×N 套适配收敛成 M+N**。
5. **谱系**：原生工具调用的下一代；同时是 OpenAPI 自动封装的替代品。

做完这五步，MCP 就不「新」了——它是你已知概念的一个坐标，外加一条新的工程约束。
