# 路由准确率

> **L5.P1 · 编排层 / 输入** · 质量面 · 进阶 / 主流

**Routing Accuracy**  ·  别名：分派正确性、调度准确率

## 一句话

请求是否被派给了正确的子 Agent 或处理路径。

## 具体是什么样

> 1000 条请求里 85 条被派错了部门，这个 8.5% 就是路由错误率，且它不会在最终指标里单独暴露。

## 看不懂？先看这几个

- [[意图分类]] — 在进入 Agent 之前先判断请求属于哪一类，路由到对应处理路径。

## 它解决什么问题

路由错误会让后续所有努力都作用在错误的轨道上，且表面看起来「有响应」。

## 它新在哪

可以且应该被单独度量（确定性判定）。把它混进端到端准确率，就永远找不到瓶颈。

## 关联概念

- [[意图分类]] — 在进入 Agent 之前先判断请求属于哪一类，路由到对应处理路径。
- [[主管模式]] — 一个中心 Agent 负责拆解与派发，子 Agent 执行后把结果汇回主管。
- [[多智能体系统]] — 多个具备独立上下文与独立决策能力的 Agent 通过分工与交接共同完成任务。
- [[多智能体评测]] — 评测编排路径本身：路由对不对、上下文丢没丢、合流时有没有失真。
- [[Agent 评测]] — 用可复现的题集与打分器，判断 Agent 在给定任务上「做得对不对」。

## 常见误判 / 坑

> [!warning] 坑
> 路由层用最强模型、下游用弱模型，导致「入口很聪明，执行很愚蠢」。资源分配应倒过来。
