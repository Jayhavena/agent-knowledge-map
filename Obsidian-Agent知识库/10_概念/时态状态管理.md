# 时态状态管理

> **L4.P7 · 控制层 / 交付** · 运维面 · 可选 / 前沿

**Temporal State**  ·  别名：版本化状态、随时间变化的事实

## 一句话

给每一条状态与事实打上时间戳与版本，能回答「当时是什么值」。

## 它解决什么问题

业务问题常带时间语义（去年同期、上个月），而 Agent 的上下文里时间是扁平的。

## 它新在哪

多数 Agent 系统把时间当作普通文本，导致「去年」被解析成当前年份。这是一个高频且隐蔽的错误源。

## 谱系

- **并行** · [[记忆冲突]]

## 关联概念

- [[语义记忆]] — 与时间无关的稳定事实：用户偏好、组织架构、领域概念。
- [[记忆冲突]] — 当新旧记忆矛盾时（用户搬了家、项目改了名），决定以谁为准。
- [[检查点]] — 在每一步之后持久化完整的执行状态，支持恢复、回滚与时间旅行调试。
- [[中断与恢复]] — 支持在任意步骤暂停（等待人工输入或外部事件），之后从断点继续。
- [[持久化执行]] — 把每一步执行记录为可重放的事件日志，进程崩溃后从最后一步继续，而不是重头再来。

## 常见误判 / 坑

> [!warning] 坑
> 忽略「相对时间」的解析。所有「上个月」「三天前」都必须在入口处转换成绝对时间戳。
