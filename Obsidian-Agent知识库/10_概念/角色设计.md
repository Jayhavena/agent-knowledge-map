# 角色设计

> **L5.P3 · 编排层 / 规划** · 机制面 · 进阶 / 争议

**Role Design**  ·  别名：人格分工、专家角色

## 一句话

为不同 Agent 设定明确的专业角色与职责边界，而非简单按流程切分。

## 它解决什么问题

无角色区分时，多个 Agent 会产出高度同质的结果，协作失去意义。

## 它新在哪

「给角色起个人设」的收益被高估了。真正的收益来自「不同的工具集 + 不同的上下文 + 不同的验收标准」。

## 关联概念

- [[系统提示]] — 在对话最前、最高优先级处声明角色、边界、可用工具与输出契约。
- [[主管模式]] — 一个中心 Agent 负责拆解与派发，子 Agent 执行后把结果汇回主管。
- [[任务简报]] — 派发子任务时给出的结构化说明：目标、边界、已知事实、输出格式、验收标准。
- [[多智能体系统]] — 多个具备独立上下文与独立决策能力的 Agent 通过分工与交接共同完成任务。

## 常见误判 / 坑

> [!warning] 坑
> 只改人设不改工具与上下文。这叫「同一模型换件衣服」，不产生真正的分工价值。
