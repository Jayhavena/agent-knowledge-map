# 幂等性

> **L3.P4 · 工具层 / 行动** · 运维面 · 进阶 / 稳定

**Idempotency**  ·  别名：重复执行安全、去重键

## 一句话

保证同一操作重复执行不产生额外副作用，是 Agent 重试机制的安全前提。

## 它解决什么问题

Agent 会重试、会恢复检查点、会被人工重跑，任何非幂等操作都可能重复扣款、重复发信。

## 它新在哪

老概念，新风险：LLM 的不确定性让「这是不是同一个操作」本身都变得难以判定。

## 关联概念

- [[检查点]] — 在每一步之后持久化完整的执行状态，支持恢复、回滚与时间旅行调试。
- [[权限范围]] — 为每个工具、每个调用方定义可访问的数据与可执行动作的最小集合。
- [[重试与退避]] — 失败后按退避策略重试，并区分可重试错误与必须立刻放弃的错误。
- [[持久化执行]] — 把每一步执行记录为可重放的事件日志，进程崩溃后从最后一步继续，而不是重头再来。

## 常见误判 / 坑

> [!warning] 坑
> 只在工具层做幂等键，忘了 Agent 会用略微不同的参数重发同一个意图。需要意图级去重。
