# 黄金集

> **L6 · 系统层 / 评测与质量（环绕全程）** · 质量面 · 核心 / 主流

**Golden Set**  ·  别名：评测集、基准题集

## 一句话

版本化的评测题集，含标准答案与判定口径，是判断回归的唯一依据。

## 具体是什么样

> 从真实日志抽 200 条问题，人工写好标准答案存下来。以后每次改 prompt 都拿这 200 条跑一遍看有没有变差。

## 看不懂？先看这几个

- [[公开基准]] — 标准化的公开评测集，用于横向比较模型或框架的通用能力。

## 它解决什么问题

没有稳定基准，每次争论都退化成「我觉得变差了」。

## 它新在哪

它是「活文档」而非一次性产物：三个来源（生产采样、历史失败、合成边界）持续汇入，并每月复审。

## 谱系

- **演进** · 回归测试（软件工程，图外旧概念）

## 被谁继承

- [[哨兵集]] — 从黄金集中挑出的十几条最高危场景，每次部署都跑，分钟级完成。

## 关联概念

- [[蒸馏]] — 用大模型生成的轨迹或概率分布训练小模型，把能力压缩进更便宜的学生模型。
- [[提示词自动优化]] — 用评测信号驱动搜索或梯度式改写提示词，替代人工试错。
- [[多智能体评测]] — 评测编排路径本身：路由对不对、上下文丢没丢、合流时有没有失真。
- [[Agent 评测]] — 用可复现的题集与打分器，判断 Agent 在给定任务上「做得对不对」。
- [[公开基准]] — 标准化的公开评测集，用于横向比较模型或框架的通用能力。
- [[回归门禁]] — 每次部署自动跑哨兵集，质量、安全、延迟、成本任一维度越界则阻断发布。
- [[失败分类法]] — 从真实生产错误反推出的一套互斥的失败类型清单，每类配独立判定口径与评测器。
- [[漂移检测]] — 持续采样线上真实流量并打分，与离线基线比对，发现无代码变更下的质量滑坡。
- [[统计显著性]] — 用置信区间判断「提升」是真实效应还是采样噪声。
- [[裁判校准]] — 定期测量模型裁判与人工标注的一致率，低于阈值就改 rubric，而不是改阈值。
- [[评测三层级]] — 工具级、单 Agent 级、多 Agent 级各有一套黄金集、评测器与晋级标准，三层都要跑。
- [[评测过拟合]] — 系统被调成「专门讨好评测集」的样子，分数一路上涨，真实使用反而变差。
- [[轨迹复盘]] — 对一次失败运行做逐步回放，定位「哪一步开始偏离」，而不是只看最终输出。
- [[部署]] — 把 Agent 服务投入生产环境并持续运行。

## 常见误判 / 坑

> [!warning] 坑
> 题集里全是「能答对的题」。必须刻意塞入 20% 已知会错的与 20% 边界模糊的，否则评测无区分度。
