# 意图分类

> **L4.P1 · 控制层 / 输入** · 质量面 · 核心 / 稳定

**Intent Classification**  ·  别名：任务路由、分诊

## 一句话

在进入 Agent 之前先判断请求属于哪一类，路由到对应处理路径。

## 它解决什么问题

单一 Agent 处理所有请求会导致提示词臃肿、行为不稳定。

## 它新在哪

老 NLP 任务在 Agent 架构里复活了，成为编排层的入口层；且常由小模型完成。

## 谱系

- **组合** · [[模型路由]]

## 被谁继承

- [[路由准确率]] — 请求是否被派给了正确的子 Agent 或处理路径。

## 关联概念

- [[模型路由]] — 按请求难度把流量分发给不同价位与能力的模型。
- [[短路与快速通道]] — 识别出简单请求后直接作答或走固定路径，不进入完整 Agent 循环。
- [[主管模式]] — 一个中心 Agent 负责拆解与派发，子 Agent 执行后把结果汇回主管。

## 常见误判 / 坑

> [!warning] 坑
> 分类错误会成为下游所有环节的隐形天花板，且极难在最终指标上被察觉。
