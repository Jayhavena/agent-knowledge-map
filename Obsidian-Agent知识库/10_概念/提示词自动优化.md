# 提示词自动优化

> **L1.P2 · 上下文层 / 取景** · 运维面 · 可选 / 前沿

**Automatic Prompt Optimization**  ·  别名：DSPy、OPRO、prompt 自动调优

## 一句话

用评测信号驱动搜索或梯度式改写提示词，替代人工试错。

## 它解决什么问题

人工调 prompt 收敛慢、不可复现，且极易过拟合少量样例。

## 它新在哪

把提示词从「人写的作品」变成「被优化的参数」，配套的代价是必须有一份可信的评测集。

## 关联概念

- [[提示词版本管理]] — 把提示词当作代码：纳入版本控制、可评审、可回滚、每次变更跑回归评测。
- [[Agent 评测]] — 用可复现的题集与打分器，判断 Agent 在给定任务上「做得对不对」。
- [[评测过拟合]] — 系统被优化成「专门讨好评测集的样子」，指标上涨但真实表现退化。
- [[黄金集]] — 版本化的评测题集，含标准答案与判定口径，是判断回归的唯一依据。

## 常见误判 / 坑

> [!warning] 坑
> 用同一份集子既优化又验收。Goodhart 效应下，指标会涨，真实长尾会退化，必须留 holdout。
