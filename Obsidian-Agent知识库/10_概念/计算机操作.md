# 计算机操作

> **L3.P4 · 工具层 / 行动** · 机制·质量面 · 进阶 / 前沿

**Computer Use**  ·  别名：GUI 智能体、屏幕操作

## 一句话

通过截图 + 坐标点击操作图形界面，绕开没有 API 的遗留系统。

## 它解决什么问题

企业内部大量系统没有 API，只有网页和桌面客户端。

## 它新在哪

把「工具」从结构化调用降级为像素级感知，通用性换来了可靠的下降与成本的上升。

## 谱系

- **演进** · [[浏览器自动化]]
- **组合** · [[多模态输入]]

## 被谁继承

- [[浏览器自动化]] — 通过 DOM 或无障碍树操作网页，比纯视觉方案更稳定、更省 token。

## 关联概念

- [[代码解释器]] — 让模型写代码并在隔离环境中执行，用代码代替自然语言做精确计算与数据处理。
- [[沙箱]] — 为代码执行与工具调用提供文件系统、网络、权限受限的隔离环境。
- [[工具返回设计]] — 决定工具返回什么、返回多少、失败时怎么说——这直接决定了模型的下一步判断质量。

## 常见误判 / 坑

> [!warning] 坑
> 在需要精确输入的场景靠视觉定位。分辨率、滚动位置、弹窗时序都会让点击落到错误元素上。
