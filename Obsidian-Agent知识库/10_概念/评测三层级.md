# 评测三层级

> **L6 · 系统层 / 评测与质量（环绕全程）** · 质量面 · 核心 / 前沿

**Tool / Agent / Multi-Agent Tiers**  ·  别名：三层评测、分层评测

## 一句话

工具级、单 Agent 级、多 Agent 级各有一套黄金集、评测器与晋级标准，三层都要跑。

## 它解决什么问题

只测 Agent 端到端，工具坏了会被 Agent 的「最佳猜测」掩盖成「Agent 有点笨」。

## 它新在哪

「Agent 的质量上限取决于它依赖的工具」——把工具当独立被测对象，是评测方法论的关键分层。

## 关联概念

- [[多智能体评测]] — 评测编排路径本身：路由对不对、上下文丢没丢、合流时有没有失真。
- [[Agent 评测]] — 用可复现的题集与打分器，判断 Agent 在给定任务上「做得对不对」。
- [[哨兵集]] — 从黄金集中挑出的十几条最高危场景，每次部署都跑，分钟级完成。
- [[链路追踪]] — 逐步记录每次运行的模型调用、工具调用、输入输出、延迟与 token，形成可检索的执行树。
- [[黄金集]] — 版本化的评测题集，含标准答案与判定口径，是判断回归的唯一依据。

## 常见误判 / 坑

> [!warning] 坑
> 只做 Agent 级就停了。工具级的错误会以「Agent 表现不稳定」的形式随机出现，永远查不到根因。
