# 代码解释器

> **L3.P4 · 工具层 / 行动** · 机制面 · 进阶 / 主流

**Code Interpreter**  ·  别名：代码执行、数据分析沙箱

## 一句话

让模型写代码并在隔离环境中执行，用代码代替自然语言做精确计算与数据处理。

## 具体是什么样

> 让它算「这 3000 行销售数据的月度环比」，模型直接心算必错，写段 pandas 跑一遍才对。

## 看不懂？先看这几个

- [[工具定义]] — 用名称、描述、参数 schema 声明一个可被模型调用的能力。

## 它解决什么问题

模型做算术、聚合、格式转换不可靠；这些恰恰是代码最擅长的。

## 它新在哪

它把「工具」从固定 API 扩展成图灵完备的动作空间，是 Agent 通用性跃升的关键一步。

## 谱系

- **组合** · [[沙箱]]
- **演进** · [[工具定义]]

## 关联概念

- [[工具选择]] — 在给定任务与可用工具集下，选出正确的工具与正确的参数。
- [[沙箱]] — 给模型生成的代码划一块隔离区：能跑，但碰不到真实文件、真实网络。
- [[计算机操作]] — 通过截图 + 坐标点击操作图形界面，绕开没有 API 的遗留系统。
- [[工具返回设计]] — 决定工具返回什么、返回多少、失败时怎么说——这直接决定了模型的下一步判断质量。
- [[工具错误处理]] — 定义工具失败时返回什么、模型如何区分「可重试」与「不可重试」。

## 常见误判 / 坑

> [!warning] 坑
> 忽略执行环境的依赖与状态。同一个脚本第二次跑不起来，模型会陷入反复修环境的循环。
