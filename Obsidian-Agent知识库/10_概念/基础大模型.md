# 基础大模型

> **L0.P2 · 模型层 / 取景** · 定义·成本面 · 核心 / 稳定

**Foundation Model / LLM**  ·  别名：底座模型、基座模型

## 一句话

通过大规模预训练获得通用语言理解与生成能力的模型，是 Agent 唯一的「思考引擎」。

## 具体是什么样

> 做一个客服问答，你不会为「识别退款意图」单独训模型，直接调通用模型即可，训练成本为零。

## 它解决什么问题

每个任务都训练专用模型成本不可承受；通用模型让「一个权重覆盖所有任务」成为可能。

## 它新在哪

地基。它新在哪里这个问题对地基不成立，判断它只需看三个参数：能力上限、上下文长度、单位 token 价格。

## 关联概念

- [[小模型·端侧模型]] — 参数量小、可本地部署的模型，用于延迟敏感、隐私敏感或高频廉价任务。
- [[模型路由]] — 按请求的难易程度，把流量分给不同价位、不同能力的模型；简单的走便宜的，难的不凑合。
- [[蒸馏]] — 用大模型生成的轨迹或概率分布训练小模型，把能力压缩进更便宜的学生模型。
- [[长上下文]] — 单次可容纳十万至百万 token 的上下文窗口，把「先检索再喂」换成「全部塞进去」。
- [[推理模型]] — 在给出答案前先生成显式长链思考的模型，把「想多久」变成可调参数。

## 常见误判 / 坑

> [!warning] 坑
> 把换模型当交付成果。同一 prompt 在不同模型上行为并不等价，回归必须重跑。
