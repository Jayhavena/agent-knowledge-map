# 沙箱

> **L3.P4 · 工具层 / 行动** · 安全面 · 核心 / 主流

**Sandbox**  ·  别名：隔离执行、容器化运行

## 一句话

为代码执行与工具调用提供文件系统、网络、权限受限的隔离环境。

## 它解决什么问题

模型生成的代码不可信，直接在生产主机执行等于把 root 交给一个会幻觉的程序。

## 它新在哪

从「测试基础设施」升级为「Agent 的安全边界」，因为 Agent 会自主决定执行什么。

## 谱系

- **组合** · [[权限范围]]

## 被谁继承

- [[代码解释器]] — 让模型写代码并在隔离环境中执行，用代码代替自然语言做精确计算与数据处理。
- [[Agent 运行时]] — 负责 Agent 的部署、扩缩容、会话隔离、状态持久化与自动埋点的执行底座。

## 关联概念

- [[小模型·端侧模型]] — 参数量小、可本地部署的模型，用于延迟敏感、隐私敏感或高频廉价任务。
- [[权限范围]] — 为每个工具、每个调用方定义可访问的数据与可执行动作的最小集合。
- [[浏览器自动化]] — 通过 DOM 或无障碍树操作网页，比纯视觉方案更稳定、更省 token。
- [[计算机操作]] — 通过截图 + 坐标点击操作图形界面，绕开没有 API 的遗留系统。
- [[数据外泄]] — 攻击者通过让 Agent 访问外部 URL、写文件、发请求，把上下文中的敏感数据带出去。

## 常见误判 / 坑

> [!warning] 坑
> 只隔离文件系统不隔离网络。数据外泄与提示注入的横向移动仍可发生。
