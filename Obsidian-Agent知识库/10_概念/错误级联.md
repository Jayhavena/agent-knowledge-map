# 错误级联

> **L5.P5 · 编排层 / 观察** · 质量面 · 进阶 / 主流

**Error Cascade**  ·  别名：误差传播、污染扩散

## 一句话

上游 Agent 的一个小错误在链路中被当作事实继续加工，逐级放大成严重偏差。

## 具体是什么样

> 检索 Agent 拿错了客户 ID，下游三个 Agent 基于这个错 ID 继续算，最后整份报告全是别人的数据。

## 看不懂？先看这几个

- [[多智能体系统]] — 多个具备独立上下文与独立决策能力的 Agent 通过分工与交接共同完成任务。

## 它解决什么问题

链式结构的每个节点都默认上游输入是正确的。

## 它新在哪

单 Agent 没有这个问题，它是多 Agent 独有的失败面，也是「多 Agent 不一定更好」的主要实证依据。

## 谱系

- **特化** · [[多智能体系统]]

## 关联概念

- [[交接]] — 把任务连同必要的上下文移交给另一个 Agent，并明确谁负责下一步。
- [[共享状态]] — 所有 Agent 读写同一份结构化状态（任务板、事实表），而不是靠消息互相传递。
- [[多智能体系统]] — 多个具备独立上下文与独立决策能力的 Agent 通过分工与交接共同完成任务。
- [[上下文传递]] — 在 Agent 之间准确传递「对方需要知道的」：约束、已确认事实、已排除路径、当前进度。
- [[多智能体评测]] — 评测编排路径本身：路由对不对、上下文丢没丢、合流时有没有失真。
- [[Agent 评测]] — 用可复现的题集与打分器，判断 Agent 在给定任务上「做得对不对」。

## 常见误判 / 坑

> [!warning] 坑
> 只在末端评测。错误在中间就发生了，末端指标只能看到「结果不对」。必须在每个交接点设断点校验。
