# 语言智能体树搜索

> **L4.P3 · 控制层 / 规划** · 机制面 · 可选 / 前沿

**LATS**  ·  别名：MCTS + LLM、蒙特卡洛树搜索

## 一句话

把「试一步、估个分、不行退回来」这种下棋式的搜索，套在 Agent 的动作上。

## 具体是什么样

> 下棋式的思路：走一步、估个分、不行退回来换一步，只不过「走一步」是调用一次工具。

## 看不懂？先看这几个

- [[思维树]] — 把推理展开成树，对多个分支做评估、剪枝与回溯，而非单线前进。

## 它解决什么问题

思维树只在推理分支里搜索，管不到「调工具之后世界变了」这种情况。

## 它新在哪

它把「探索-利用权衡」带进 Agent 决策，是当前最接近「会试错的智能体」的学术形态。

## 谱系

- **演进** · [[思维树]]

## 关联概念

- [[测试时计算扩展]] — 在推理阶段投入更多采样、搜索或验证算力，用时间换准确率。
- [[Agent 循环]] — 「想一想、动一下、看看结果」反复循环，直到任务做完或该停为止——需要多步外部交互的 Agent 的骨架。
- [[思维树]] — 把推理展开成树，对多个分支做评估、剪枝与回溯，而非单线前进。
- [[自洽投票]] — 对同一问题采样多条推理路径，取多数一致的答案。

## 常见误判 / 坑

> [!warning] 坑
> 在真实有副作用的动作上做搜索。回滚不了的操作（发邮件、下单）不能进搜索树。
