# 结构化输出

> **L1.P7 · 上下文层 / 交付** · 机制·质量面 · 核心 / 稳定

**Structured Output**  ·  别名：JSON mode、schema 约束解码

## 一句话

强制模型只输出符合约定格式的 JSON 等结构，程序可以直接解析，不用从文本里抠。

## 具体是什么样

> 要求返回 {"sentiment":"positive","confidence":0.9}，程序直接解析字段，不用写正则去抠文本。

## 看不懂？先看这几个

- [[提示词模板]] — 带占位符的提示词字符串，将任务说明与运行时变量拼装成最终输入。

## 它解决什么问题

自由文本的输出没法稳定解析，靠正则去抠，输出一长几乎必错。

## 它新在哪

从「提示模型别写废话」进化为「解码时约束 token 概率」，把合规性从祈祷变成保证。

## 关联概念

- [[原生工具调用]] — 模型直接输出结构化调用指令，而非在自由文本里夹带「我想调用某函数」的意图。
- [[少样本示例]] — 在提示中给出若干输入输出样例，用模式匹配替代显式规则描述。
- [[提示词模板]] — 带占位符的提示词字符串，将任务说明与运行时变量拼装成最终输入。
- [[工具定义]] — 用名称、描述、参数 schema 声明一个可被模型调用的能力。
- [[工具错误处理]] — 定义工具失败时返回什么、模型如何区分「可重试」与「不可重试」。
- [[Agent 评测]] — 用可复现的题集与打分器，判断 Agent 在给定任务上「做得对不对」。

## 常见误判 / 坑

> [!warning] 坑
> schema 合法不代表语义合法。字段齐全但值错位的「结构性正确」是最难发现的一类失败。
