# 小模型 / 端侧模型

> **L0.P2 · 模型层 / 取景** · 成本·时延面 · 可选 / 主流

**Small Language Model / On-device**  ·  别名：SLM、端侧推理

## 一句话

参数量小、可本地部署的模型，用于延迟敏感、隐私敏感或高频廉价任务。

## 具体是什么样

> 手机输入法联想必须在本机 50ms 内出结果，云端大模型再强也来不及，只能用小模型。

## 看不懂？先看这几个

- [[基础大模型]] — 通过大规模预训练获得通用语言理解与生成能力的模型，是 Agent 唯一的「思考引擎」。

## 它解决什么问题

云端大模型在延迟、数据出境、单位成本上都存在不可逾越的下限。

## 它新在哪

不是新事物，而是新约束（量化、蒸馏、端侧算力）让旧路线重新可行。

## 谱系

- **演进** · [[蒸馏]]

## 关联概念

- [[基础大模型]] — 通过大规模预训练获得通用语言理解与生成能力的模型，是 Agent 唯一的「思考引擎」。
- [[模型路由]] — 按请求的难易程度，把流量分给不同价位、不同能力的模型；简单的走便宜的，难的不凑合。
- [[蒸馏]] — 用大模型生成的轨迹或概率分布训练小模型，把能力压缩进更便宜的学生模型。
- [[沙箱]] — 给模型生成的代码划一块隔离区：能跑，但碰不到真实文件、真实网络。
- [[部署]] — 把 Agent 服务投入生产环境并持续运行。

## 常见误判 / 坑

> [!warning] 坑
> 用通用 benchmark 挑选小模型。小模型的强项高度任务特定，必须在自己的黄金集上选。
