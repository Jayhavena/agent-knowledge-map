# 短路与快速通道

> **L4.P3 · 控制层 / 规划** · 时延·成本面 · 进阶 / 主流

**Short-circuit / Fast Path**  ·  别名：简单问题直答、绕过循环

## 一句话

识别出简单请求后直接作答或走固定路径，不进入完整 Agent 循环。

## 它解决什么问题

用多步循环处理「你好」这类请求，延迟与成本都被放大十倍。

## 它新在哪

它是模型路由在控制层的对应物：不是所有流量都值得走最贵的路径。

## 谱系

- **并行** · [[模型路由]]
- **特化** · [[Agent 循环]]

## 关联概念

- [[模型路由]] — 按请求难度把流量分发给不同价位与能力的模型。
- [[意图分类]] — 在进入 Agent 之前先判断请求属于哪一类，路由到对应处理路径。
- [[Agent 循环]] — 「思考 → 行动 → 观察」反复迭代直至终止条件满足的主控循环，是所有 Agent 的骨架。
- [[终止判据]] — 明确定义「任务算完成」「该放弃」「该升级给人」的判据，而不依赖模型的自我感觉。
- [[时延预算]] — 把端到端时延预算拆分到每一层（入口、检索、模型、工具），并分别设上限。

## 常见误判 / 坑

> [!warning] 坑
> 短路判据过宽，把本该多步处理的问题也直答掉了，表现为「偶尔答得很敷衍」。
