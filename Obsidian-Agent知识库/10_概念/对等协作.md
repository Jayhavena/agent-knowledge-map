# 对等协作

> **L5.P3 · 编排层 / 规划** · 机制面 · 可选 / 前沿

**Swarm / Peer-to-Peer**  ·  别名：去中心化协作、自主交接

## 一句话

无中心节点，Agent 之间按规则直接把控制权交给下一个合适的 Agent。

## 它解决什么问题

中心调度者会限制并发与灵活性，长流程中成为单点瓶颈。

## 它新在哪

把控制流从「预定义的图」变成「运行时涌现的路由」，灵活性提升的代价是可预测性下降。

## 谱系

- **特化** · [[多智能体系统]]

## 关联概念

- [[终止判据]] — 明确定义「任务算完成」「该放弃」「该升级给人」的判据，而不依赖模型的自我感觉。
- [[主管模式]] — 一个中心 Agent 负责拆解与派发，子 Agent 执行后把结果汇回主管。
- [[交接]] — 把任务连同必要的上下文移交给另一个 Agent，并明确谁负责下一步。
- [[多智能体系统]] — 多个具备独立上下文与独立决策能力的 Agent 通过分工与交接共同完成任务。

## 常见误判 / 坑

> [!warning] 坑
> 缺少全局终止条件时会出现两个 Agent 互相推诿、无限交接。
