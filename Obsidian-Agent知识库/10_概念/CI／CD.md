# CI/CD

> **L6 · 系统层 / 运行与发布（环绕全程）** · 运维面 · 可选 / 稳定

**CI/CD**  ·  别名：持续集成、持续交付

## 一句话

自动化地构建、测试、部署的工程流水线。

## 具体是什么样

> 每次 push 自动跑测试并部署到预发，合并到 main 自动上生产——没有这套，评测门禁无处可挂。

## 它解决什么问题

手工发布不可复现、不可审计、频率低。

## 它新在哪

不是新东西。但它作为「评测门禁」的宿主，是 Agent 工程化绕不开的前置条件。

## 被谁继承

- [[发布策略]] — 决定数据、工具、提示词、模型四者的变更如何协同上线，避免半新半旧状态。

## 关联概念

- [[提示词版本管理]] — 把提示词当作代码：纳入版本控制、可评审、可回滚、每次变更跑回归评测。
- [[Agent 评测]] — 用可复现的题集与打分器，判断 Agent 在给定任务上「做得对不对」。
- [[回归门禁]] — 每次部署自动跑哨兵集，质量、安全、延迟、成本任一维度越界则阻断发布。
- [[部署]] — 把 Agent 服务投入生产环境并持续运行。

## 常见误判 / 坑

> [!warning] 坑
> 团队缺少 CI 文化时硬上评测门禁。流程会先压垮人，而不是先发现问题。
