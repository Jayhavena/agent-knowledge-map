# 工具返回设计

> **L3.P5 · 工具层 / 观察** · 机制·质量面 · 核心 / 主流

**Tool Result Design**  ·  别名：返回值契约、观察格式

## 一句话

决定工具返回什么、返回多少、失败时怎么说——这直接决定了模型的下一步判断质量。

## 它解决什么问题

原样返回 50KB JSON，模型会被噪声淹没；只返回「成功」，模型就失去了纠错依据。

## 它新在哪

它长期被忽视，因为传统 API 设计假设消费者是程序。消费者换成模型后，返回值的「可读性」变成一等需求。

## 常见误判 / 坑

> [!warning] 坑
> 返回「看起来对」的结果。截断、分页、缓存过期产生的残缺数据，模型会当成完整事实使用。
