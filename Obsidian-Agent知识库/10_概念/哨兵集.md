# 哨兵集

> **L6 · 系统层 / 评测与质量（环绕全程）** · 质量·时延面 · 核心 / 主流

**Sentinel Set**  ·  别名：高危用例子集、快速回归集

## 一句话

从黄金集中挑出的十几条最高危场景，每次部署都跑，分钟级完成。

## 具体是什么样

> 黄金集里挑出 15 条「答错就是事故」的题，每次提交代码跑一遍，两分钟出结果。

## 看不懂？先看这几个

- [[黄金集]] — 版本化的评测题集，含标准答案与判定口径，是判断回归的唯一依据。

## 它解决什么问题

全量评测跑一次要几十分钟，不可能每次提交都跑。

## 它新在哪

速度与覆盖不可兼得，分层是唯一解法：哨兵管「每次」，黄金集管「发布前 / 每日」。

## 谱系

- **特化** · [[黄金集]]

## 被谁继承

- [[回归门禁]] — 每次部署自动跑哨兵集，质量、安全、延迟、成本任一维度越界则阻断发布。

## 关联概念

- [[Agent 评测]] — 用可复现的题集与打分器，判断 Agent 在给定任务上「做得对不对」。
- [[评测三层级]] — 工具级、单 Agent 级、多 Agent 级各有一套黄金集、评测器与晋级标准，三层都要跑。
- [[部署]] — 把 Agent 服务投入生产环境并持续运行。
- [[黄金集]] — 版本化的评测题集，含标准答案与判定口径，是判断回归的唯一依据。

## 常见误判 / 坑

> [!warning] 坑
> 让哨兵集承担覆盖职责。十几条题只能防「已知的致命错误」，不能证明「没有新错误」。
