# Agent 外壳

> **L6 · 系统层 / 运行与发布（环绕全程）** · 定义·机制面 · 核心 / 主流

**Harness / Scaffold**  ·  别名：脚手架、agent framework、编排外壳

## 一句话

包在模型外面的那一层代码：循环、工具注册、上下文拼装、权限、日志，全部由它负责。

## 它解决什么问题

同一个模型，换一套外壳，任务成功率能差出一倍——能力不只来自模型。

## 它新在哪

「模型 + 外壳 = 系统能力」这个认识正在取代「换个更强的模型就好了」。它是本图 L1–L6 的整体指称。

## 谱系

- **演进** · [[Agent 循环]]

## 关联概念

- [[上下文工程]] — 系统性决定「每次调用时模型眼前摆什么 token」的工程实践，涵盖选取、排序、压缩、格式化与缓存。
- [[Agent 循环]] — 「思考 → 行动 → 观察」反复迭代直至终止条件满足的主控循环，是所有 Agent 的骨架。
- [[Agent 评测]] — 用可复现的题集与打分器，判断 Agent 在给定任务上「做得对不对」。
- [[Agent 运行时]] — 负责 Agent 的部署、扩缩容、会话隔离、状态持久化与自动埋点的执行底座。
- [[链路追踪]] — 逐步记录每次运行的模型调用、工具调用、输入输出、延迟与 token，形成可检索的执行树。

## 常见误判 / 坑

> [!warning] 坑
> 把外壳当成可替换的胶水。上下文拼装顺序、工具描述、终止判据全在外壳里，换掉等于换系统。
